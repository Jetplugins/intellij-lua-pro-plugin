# Security policy

Do not report security vulnerabilities in public issues.

Use [GitHub's private vulnerability reporting](https://github.com/Jetplugins/intellij-lua-pro-plugin/security/advisories/new) to share the affected Lua Pro version, impact, reproduction steps and supporting material privately with the maintainers.

Include the IDE and build, operating system, Lua/Luau runtime, language-server provider and relevant tool versions. Remove credentials, license keys, proprietary source code, personal information and unrelated confidential information from reports and attachments.
